Backports the two-integer `GL_POLYGON_MODE` query from Distant Horizons !126.

- Requires DH **3.3.3**, Minecraft **1.21.1**, NeoForge **21.1.263+ within 21.1.x**, Java **21**.
- Install `dh-polygon-fix-1.0.0-mc1.21.1-neoforge.jar` alongside official DH on clients.
- Applies to all client platforms; no server installation is needed.
- Remove this patch before upgrading DH.
- Preserves the DH 3.3.3 interfaces used by Separate Sable Render Distance.

The sources JAR and complete project source ZIP are for development, not installation.
Checksums are supplied in `SHA256SUMS` and `SHA512SUMS`.
